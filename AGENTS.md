# Repository instructions

## Agent skills

### Issue tracker

Issues, PRDs, and implementation tickets live in GitHub Issues for `Vaibtan/XpensGo`. Use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage roles defined in `docs/agents/triage-labels.md`.

### Domain docs

Xpensego uses a single-context domain layout. Read the root `CONTEXT.md` and relevant ADRs under `docs/adr/`. See `docs/agents/domain.md`.
