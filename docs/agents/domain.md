# Domain docs

Xpensego uses a single-context domain layout.

## Before exploring

- Read the root `CONTEXT.md`.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If either location is absent, proceed without requesting speculative documentation.

## Conventions

- Use the canonical terminology defined in `CONTEXT.md`.
- Do not replace glossary terms with synonyms it explicitly avoids.
- If required terminology is missing, record it for the domain-modeling workflow.
- Surface conflicts with accepted ADRs rather than silently overriding them.
